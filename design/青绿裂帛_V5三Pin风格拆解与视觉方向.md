## 2. 合成后的原创方向

“青绿裂帛”不是把三张海报贴到 App 上，而是建立一套新的产品语法：

- Pin 1 负责信息与字体骨架；
- Pin 2 负责主色、绘画面积和生命力；
- Pin 3 负责纸层、线稿和留白；
- 饮品实拍、日历、AI 推荐、发布表单与用户档案仍来自本产品自身需求。

一句话：**一杯饮品被收进一册青绿矿物色的当代艺术展刊。**

## 3. 视觉系统

| 语义 | 色值 |
|---|---|
| 宣纸米白 | `#E9E7DC` |
| 炭墨 | `#272923` |
| 矿物青 | `#075E49` |
| 孔雀绿 | `#148263` |
| 青蓝 | `#3AA89A` |
| 雾薄荷 | `#BFD8CA` |
| 风化石 | `#C8C3B4` |
| 朱红点色 | `#C84F43` |
| 钴蓝点色 | `#416C9A` |

- 标题：高对比中文宋体与少量压缩粗体汉字组合。
- 正文与操作：中性无衬线，保证按钮、日历和表单清晰。
- 图像：真实饮品照片可网点化、降色或嵌入撕纸层，不加白边贴纸。
- 形状：0–6px 圆角，主要依赖锐利矩形、纸边与细线，不使用大面积胶囊按钮。
- 质感：纸纤维、丝网错位、复印网点、干刷颜料；控件文字仍保持锐利。
- 景深：来自纸张重叠与颜料色层，不使用玻璃拟态和悬浮阴影。

## 4. 四个模块

### 记录

“七月记饮”作为拆分式大标题；日历融入展览海报网格，已记录日期用网点饮品缩略图标记，当前日期用不规则细圆圈出。

### 创作

真实饮品照片嵌入青绿颜料、撕纸和建筑线稿。免费工具在前；AI 只给“青绿画报”“纸上建构”两项推荐。

### 发布

作品预览本身是一张可收藏的 4:5 文化海报；标题、正文、标签和导出操作保持规则、可编辑。

### 我的

像展览图录索引：记录数、城市、月刊、历史作品、城市足迹、会员次数、隐私与数据依次排列，不使用可爱头像或护照印章。

## 5. 与 V4 的断开

- 不再使用奶油粉彩、圆角卡片和饮品白边贴纸。
- 不再使用可爱粗圆字体、星星、棋盘格和卡通头像。
- 日历从“可爱贴纸收集”变为“艺术展览目录”。
- 海报从文具感变为青绿矿物绘画与当代中文排版。
- 产品气质从轻甜可爱切换为成熟、实验、文化刊物感。
