# 《AI 饮品生活日记》V3 竞品研究与视觉方向：雾刊编辑室

> 状态：视觉原型评审，未进入前端开发  
> 日期：2026-09-03  
> 使用 Skill：`awesome-design-md-art-direction`  
> 上游集合：VoltAgent `awesome-design-md`，本地版本 `8147538`

## 1. 这次要解决的问题

V2 的情绪方向是对的，但“木板、旧纸、撕边、票据、印章”同时出现在四个主页面，材质密度过高，形成了复古手账素材包的观感。它很有气氛，却不够雅致，也让照片、内容层级和现代产品感退到了后面。

V3 不再用更多装饰证明“文艺”，而用四件事形成文艺感：

1. 电影感照片；
2. 克制的中文宋体标题；
3. 大留白与编辑式错位构图；
4. 少而准确的材质细节。

一句话方向：**像雨天咖啡馆里的一本独立生活刊物，但操作起来仍是一款安静、清楚、现代的 App。**

## 2. 公开竞品与相邻产品研究

### 2.1 已确认的产品证据

| 来源 | 已确认现象 | 本产品吸收 | 不吸收 |
|---|---|---|---|
| [Day One](https://dayoneapp.com/) | 内容优先；照片可形成媒体网格；支持按日期回看；隐私、备份和导出被明确呈现 | 让照片和回忆检索成为主角；在“我的”中把隐私与导出做成一级可见能力 | 不照搬蓝色品牌色、导航和页面构图 |
| [NOMO CAM](https://apps.apple.com/cn/app/nomo-cam-%E4%BD%A0%E7%9A%84%E6%8B%8D%E7%AB%8B%E5%BE%97/id1362548649) | 相机界面极度单一，模拟真实相机外观；胶片质感发生在照片结果中，而不是给所有 UI 加旧纸 | 创作页让照片占最大面积；免费滤镜用少量、明确、可预览的相机式样本 | 不复制相机机身、镜头造型和品牌相机皮肤 |
| [Moli](https://apps.apple.com/cn/app/moli-ai%E7%85%A7%E7%89%87%E6%97%A5%E8%AE%B0/id6474176378) | “拍照—记录想法—AI 回应”路径直白；宣传截图以大照片和黑白界面为主 | AI 在照片之后出现；AI 负责理解、回应和整理，不抢走记录主流程 | 不使用聊天气泡作为全产品的主视觉 |
| [素忆](https://suyiriji.com/) | 大留白、传统中文字体、纸张感、极简线描；首页用极少元素建立安静气质 | 用宋体与留白建立文学感；纸张是阅读面，不是每张卡片的贴图 | 不照搬水墨山形、印章 Logo 和竖排品牌开屏 |
| [Moodiary](https://github.com/ZhuJHua/moodiary) | 列表、日历、媒体和设置分工明确；支持多端、主题、字体、多媒体、隐私与导出 | 保留成熟工具的信息层级；记录、日历、媒体与设置不混成瀑布流 | 不照搬 Material 组件外观，也不把功能全塞进首页 |
| [Memex](https://github.com/memex-lab/memex) | 允许用文字、照片、语音碎片记录，再由 AI 组织为卡片、时间线和洞察；强调本地优先 | AI 可在未来承担月刊整理、回忆检索和轻陪伴；原始记录仍可独立存在 | 不把复杂 Agent、知识库术语暴露给普通用户 |

### 2.2 短视频与内容平台观察

【已确认】抖音公开结果中出现“透明感手帐设计”“3 种简单好看手帐排版”等内容标题，说明手帐受众确实关注透明叠层、版面节奏和可复用排版，而不只是滤镜本身。

【访问限制】当前环境没有可连接的登录浏览器实例，小红书与 B 站未获得足够稳定的笔记/视频正文与逐帧界面证据。因此本轮不把搜索摘要当成已确认视觉事实，也不声称复刻这些平台的具体作品。V3 只使用公开可核实的产品页、App Store 截图和 GitHub 项目界面作为直接证据。

### 2.3 研究结论

- “高级”来自秩序：照片是最大视觉面积，标题是第二层，工具和装饰退到第三层。
- “文艺”来自编辑判断：留白、裁切、字体、节奏，比木纹、胶带、印章的数量更重要。
- “生活记录”需要安静：默认私密、快速记录、可回看，比公开社区和连续打卡更适合本产品。
- “AI 产品”不等于聊天框：AI 应出现在读图推荐、艺术化、文案、月刊和回忆检索中。
- “免费与会员”要视觉分层：免费修图是稳定工具；AI 推荐只显示两项；生成前明确会员次数和失败返还。

## 3. Awesome DESIGN.md 的组合方法

本轮完整阅读并组合了三份上游 `DESIGN.md`：

| 角色 | 来源 | 取用原则 | 明确舍弃 |
|---|---|---|---|
| 主导语言 | `claude/DESIGN.md` | 暖白画布、文学型衬线标题、人文无衬线正文、深浅表面交替、以色块而非阴影分层 | 品牌珊瑚色、品牌字形、AI 官网构图 |
| 摄影与深色画布 | `runwayml/DESIGN.md` | 电影照片占主导、界面退后、零阴影、细冷灰元数据、非对称编辑网格 | 品牌黑白体系、全屏营销页结构、专有字体 |
| 产品清晰度 | `notion/DESIGN.md` | 8px 控件、12px 卡片、真实产品界面、清楚的标签与表单层级 | 紫色主按钮、彩色便签、品牌插画和网页布局 |

【适配】三个来源只贡献可迁移的规则，不使用 Logo、专有字体、原始品牌色、营销文案或完整页面构图。

【原创】把这些规则连接成“雾刊编辑室”：骨白纸面、雾蓝黑、电影雨景、酒梅点色、少量烟熏木和一处不规则纸边。

## 4. V3 视觉系统

### 4.1 审美配比

- 45% 独立刊物的留白与排版；
- 30% 雨天电影照片与暗部；
- 20% 现代工具的清楚和克制；
- 5% 木质、纸边、编号、酒梅色等手工痕迹。

### 4.2 色彩令牌

| 令牌 | 色值 | 用法 |
|---|---|---|
| 雾夜 | `#17201F` | 创作画布、底栏、照片衬底；不用纯黑 |
| 深墨 | `#242B2A` | 主文字、深色卡片 |
| 骨白 | `#F2EFE8` | 记录、发布、我的的主要阅读面 |
| 灰纸 | `#E5E1D8` | 次级卡片和表单层次 |
| 雨雾 | `#697674` | 元数据、未选中项；大字使用 |
| 苔灰 | `#52635D` | 保存、私密、稳定状态 |
| 酒梅 | `#754B57` | 主操作和情绪点色；单屏不超过 6% |
| 旧金 | `#A58C68` | AI 会员和轻微编号；只做微量信号 |
| 烟木 | `#5B493F` | 仅出现在照片、极细分隔或一块小样本中 |

### 4.3 字体与层级

- 中文展示标题：`Source Han Serif SC / Noto Serif CJK SC`，400–500，避免粗黑宋体。
- UI 与正文：`PingFang SC / Noto Sans SC`，400–500。
- 数字与刊号：同一无衬线字体，使用小号大字距，不额外引入打字机字体。
- 页面标题 28–32px，记录标题 20–24px，正文 15–16px，元数据 11–13px。
- 标题可有轻微不对称和跨栏，但按钮、价格、会员次数、错误信息必须在规则网格上。

### 4.4 形状、层次与材质

- 标准卡片圆角 10–12px；按钮 8px；相片可 2–4px 或直角。
- 默认无投影；通过骨白/灰纸/雾夜色块和照片景深建立层次。
- 每屏最多一处纸张不规则边，只能用于照片或作品预览，不用于按钮和表单。
- 不出现满屏木纹；木质只允许在真实咖啡馆照片中自然出现。
- 不使用成套贴纸、胶带、仿旧污渍、邮戳、皮革、黄铜包边。
- 拼贴改为“编辑式蒙太奇”：一张主照片 + 一条半透明题注 + 一块极小的裁切纹理。

### 4.5 摄影规则

- 真实饮品、书、窗、手部和桌面，避免过度商业摆拍。
- 冷色雨窗与室内暖灯形成低饱和冷暖对比。
- 保留阴影和黑位，不做 HDR，不使用高饱和橙棕复古预设。
- 允许主体偏离中心，给标题和日期留出真实负空间。

## 5. 四个模块的代表页面

### 5.1 记录

- 骨白阅读面，顶部只放日期、城市与一句短标题。
- 一张大照片占首屏约 42%，题注轻压在照片边缘，不再贴票据。
- 主操作“记下这一杯”，次操作“从相册选”。
- 下方是紧凑月历和两张近期记录，不做无限瀑布流。
- 文艺感来自照片裁切、标题留白与细日期线，而不是旧纸装饰。

### 5.2 创作

- 雾夜画布，大图占约 55%–60%，工具界面尽量隐形。
- 免费区先出现：滤镜、调整、裁切、版式、贴纸；六款滤镜横向展示。
- AI 区只出现两张大卡：“留白刊物”“纸上留影”，各自有推荐理由和保真说明。
- 会员信号使用一条旧金色细线和文字“本次使用 1 次 · 失败返还”，不用金色 VIP 大卡。

### 5.3 发布

- 骨白编辑台，顶部切换“小红书 / 朋友圈”。
- 4:5 作品预览像一页摄影杂志：照片、短标题、日期地点，保留足够空白。
- 标题、正文、标签为清楚的规则表单；AI 只提供少量候选，不制造大段花哨文案。
- 固定操作：“保存图片”“复制文案”“系统分享”。

### 5.4 我的

- 标题改为“我的日常档案”，不再伪装成复古护照封面。
- 用户信息、本月数据、历史作品、饮品护照、会员次数、隐私与导出分成清楚模块。
- 城市印章收敛为小型线性标记；统计以排版数字呈现，不画卡通杯子。
- 未登录仍可本地记录，登录/注册是数据同步和恢复入口，不阻挡第一杯。

## 6. 原型验收门槛

- 四个手机屏幕均有一致的四底栏：`记录 / 创作 / 发布 / 我的`。
- 记录、免费滤镜、恰好两个 AI 推荐、发布文案、历史/会员/隐私均可辨认。
- 至少两个页面为浅色阅读面，创作页可使用深色画布，避免整套产品长期压抑。
- 木纹、撕纸、票据、印章合计视觉占比不得超过单屏 5%。
- AI 会员信息清楚但不喧宾夺主；不能把免费滤镜伪装成 AI。
- 不使用竞品 Logo、品牌文案、专有字形或一比一界面构图。
- 小号中文若因图像生成出现误差，只用于方向评审；开发稿必须以本文和 PRD 文案为准。

## 7. 与 V2 的直接差异

| V2 雨木拼贴 | V3 雾刊编辑室 |
|---|---|
| 材质证明文艺 | 排版与摄影形成文艺 |
| 四屏都是暗木和旧纸 | 浅色阅读面与深色创作面交替 |
| 撕边、票据、印章多次出现 | 每屏最多一处编辑式不规则细节 |
| 怀旧手账感强 | 当代独立刊物感更强 |
| 装饰层抢过产品功能 | 功能层级清楚，装饰退后 |
| 木质约 30%–40% | 木质约 5%，主要存在于照片中 |

当前结论：V3 更适合成为默认品牌方向；V2 可保留为未来“雨木手账”主题皮肤，不再作为全局默认 UI。

## 8. 本轮生成结果与检查

- 原型图：`design/AI饮品生活日记_雾刊编辑室_V3_四模块原型.png`
- 画布：1536 × 1024 PNG
- 四模块：记录、创作、发布、我的均完整出现，底栏选中态随页面变化。
- 创作分层：免费滤镜先于 AI；AI 推荐恰好两项；会员次数与失败返还可见。
- 视觉结果：三块骨白阅读面与一块雾夜创作面交替；木纹、撕纸、票据和印章已退出全局 UI。
- 已知生成误差：少量小号中文和缩略图标签可能有笔画偏差；大标题、模块和主操作可辨。后续真实前端需使用本文规定的准确文案和字体，不从位图抄字。
