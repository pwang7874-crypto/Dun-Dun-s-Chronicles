# 《AI 饮品生活日记》雨木拼贴 V2 视觉方向说明

> 状态：原型评审，未进入开发  
> 日期：2026-09-03  
> 适配 Skill：`awesome-design-md-art-direction`

## 一句话方向

一本在雨天咖啡馆的胡桃木桌上，被照片、旧纸、票据和雨痕慢慢拼起来的私人饮品日记。

## 来源组合

【已确认】本轮从 VoltAgent `awesome-design-md` 中完整阅读三份相关设计文档：

- `starbucks/DESIGN.md`：只提取暖咖啡材质、深浅表面分层、实物卡片感和色块节奏。
- `runwayml/DESIGN.md`：只提取电影感摄影、深色画布、冷灰元数据、非对称编辑网格和低阴影。
- `clay/DESIGN.md`：只提取有机不规则构图、手工材质感、有限强调色和 44px 控件原则。

【适配】没有使用三个品牌的 Logo、专有字体、吉祥物、原始配色、营销文案或完整页面构图。

【原创】把三个来源连接为“雨木拼贴”：暗胡桃木 + 雨玻璃灰蓝 + 燕麦纸 + 氧化黄铜 + 手撕边界。

## 拼贴语法

每个页面最多使用：

1. 一张占主导地位的真实饮品照片。
2. 一处手撕纸边。
3. 一张日期、票据或档案编号小纸片。
4. 一处胶带或印章，不重复堆叠。
5. 一处黄铜或湿玫瑰点色。

手撕边只作为层级边界，不能充当按钮轮廓；表单、价格、额度、错误提示仍放在平整、清楚的阅读区域。

## 四模块表达

- **记录**：雨窗照片像刊物封面；月历像撕下来的账页；近期记录采用小型接触印样。
- **创作**：像一张暗房工作台；照片最大；免费滤镜优先；AI 只显示“纸上留影”和“丝网记忆”两个推荐。
- **发布**：像正在装订的 4:5 手撕海报，但标题、正文、标签仍是稳定的表单行。
- **我的**：像私人田野笔记与饮品护照；印章克制使用；会员次数和隐私入口保持透明。

## 与 V1 的区别

| V1 诗性纸刊 | V2 雨木拼贴 |
|---|---|
| 明亮米白、日光、安静杂志 | 深胡桃木、雨窗、电影式阴影 |
| 平整纸页和细线网格 | 手撕纸边、档案碎片和轻重叠 |
| 轻盈、适合日常默认主题 | 情绪更强、辨识度更高，适合品牌主视觉或主题皮肤 |
| 更稳妥、更通用 | 更新奇、更文艺，但更需要控制可读性 |

## 原型检查

【已确认】四个模块均完整出现，底栏结构一致；记录、免费编辑、两个 AI 推荐、发布表单、护照、会员和隐私均可辨识。

【已确认】雨窗、暗木、燕麦纸、手撕边与黄铜点色形成统一材质逻辑，创意强于 V1。

【已知限制】图像模型生成的少量小号中文、日期和缩略图标签可能出现笔画或内容误差。原型只用于评审视觉方向，产品文字和功能定义仍以前端设计方案与 PRD 为准。

## 建议使用方式

建议把 V2 作为品牌主视觉候选，同时保留 V1 的浅色阅读面：

- 首页、创作画布和月刊封面可以采用 V2 深色雨木环境。
- 长表单、设置、隐私、支付和错误恢复使用 V1 的浅色纸面。
- 不建议整套产品所有页面都保持最深色，以免长期使用压抑、文字对比疲劳。

当前仍处于设计冻结状态，用户确认前不修改前端代码。
