# 吨吨记｜成熟阶段开发状态

更新时间：2026-09-03

## 已冻结的产品决定

- 首发市场：中国大陆。
- 客户端：React Native 同时覆盖 iOS 15.1+ 与 Android API 24+。
- 免费层：记录、普通修图、普通滤镜永久免费，端侧处理。
- AI 层：首次赠送 1 次；会员价 ¥18/月、¥128/年；会员每天 1 次（北京时间 00:00 恢复、不累计）；失败返还。
- AI 供应商：火山方舟 Doubao-Seedream-5.0-lite，当前官方标价约 ¥0.22/张；真实密钥只放服务端。
- 品牌合作：没有真实合作方前只建设基础设施与诚实空状态，不展示虚构品牌、优惠券或联名。

## 本轮已完成

### 四模块信息架构

- `记录`：月历与留影墙双视图、草稿恢复、记录详情入口。
- `创作`：横向免费滤镜/调整/裁切/贴纸/排版，支持旋转、翻转、±15° 拉直和 20 步撤销/重做；AI 默认只展示两项推荐，可展开全部四种。
- `发布`：小红书、朋友圈两种渠道预览；文案草稿入库；可复制、保存完整海报并调用系统分享面板。
- `我的`：登录/注册入口、收藏、历史海报、会员规则、原创饮印册、饮品护照、挑战、本地搜索、本月小刊和隐私数据入口。

### 新手指南

- 首次打开 App 自动展示四页可跳过教程，依次介绍日历记录、穿搭/美食贴图、六款免费滤镜与会员 AI、双渠道发布和印章收藏。
- 完成或跳过会把完成时间写入本地资料，冷启动不再重复打扰；“我的 → 新手指南”保留永久重播入口。
- 删除全部本地数据会同时重置教程状态，符合新设备/新用户重新引导的预期。

### 免费滤镜

在原有 Skia 非破坏式渲染链中增加 6 款原创、端侧、无 API 成本滤镜：

1. 奶油晨光
2. 胶片午后
3. 雨天咖啡馆
4. 可可棕
5. 夜色霓虹
6. 黑白札记

滤镜 ID、版本、强度、亮度、对比度、饱和度、色温、裁切、旋转、翻转、拉直角度和源资产继续写入 `EditRecipeV1`；保存成片与缩略图时使用同一配方，原图不覆盖。

### AI Style 方向

- 白页刊物：基于 MIT 的 `gc-minimal-zine-poster` 规则做饮品适配。
- 纸上留影：基于 MIT 的 `photo-relic-editorial` 规则做饮品适配。
- 丝网记忆：基于 MIT、无捆绑资产的 `photo-riso-poster` 规则做饮品适配。
- 水彩日记：编写项目自有 StyleSpec，不使用来源未充分核实的参考资产。
- 原计划“旧时绘本”因视觉参考资产商用授权未冻结，暂不进入上线目录。

任何外部 Skill 进入产品前必须固定来源 commit、保留许可证、移除示例图依赖并经过 8 类代表照片质量测试。

### 本地留存与隐私

- 收藏、渠道文案草稿、创作选项和 AI 任务表进入 SQLite Schema V5；穿搭/美食生活贴图进入 Schema V6；新手教程完成状态进入 Schema V7。
- 每条饮品记录可继续添加穿搭照与美食照；支持的真机会在设备端抽取主体并生成透明 PNG，同时私密保留原图。无法抽取时明确使用“原图贴纸”，不伪装成功。
- 生活贴图可命名、移除，并在创作画布上调整位置、大小和旋转；记录详情与最终分享海报都会读取同一组持久化数据。
- 城市护照、店铺/类别挑战和回忆搜索只使用用户主动填写的数据，不申请定位。
- 本月小刊使用真实月度记录进行本地排版，页尾可编辑，可复制总结并保存图片。
- 隐私页可导出 JSON；删除全部数据有二次确认，并同时清理数据库和 App 私有照片。
- iOS 海报写入支持“仅添加照片”的最小权限；已固化第三方相册库误报失败的原生补丁。

## 安全与空间记录

- `npm audit --omit=dev` 报告 7 个 moderate、8 个 high。
- high 来自 React Native 0.87.1 的 Metro → `image-size@1.2.1` 构建链，当前不进入 App 运行时，也不接收用户照片。
- moderate 来自 React Navigation → `query-string` → `decode-uri-component`；当前未开放 deep link，开放前必须增加输入长度限制与坏例测试。
- 自动修复会强制降级 React Native，当前不执行破坏性 `npm audit fix --force`。
- 最终 ARM64 构建后已将 APK 移至独立产物目录并执行 `gradlew clean`；本轮清除约 2.3GiB Android 中间文件，连同此前清理后当前磁盘可用空间约 24GiB。

## 外部配置门

以下能力已有客户端入口和诚实失败态，但没有外部配置就不能标记为真实可用：

1. 火山方舟 Seedream：HTTPS 服务端地址、模型标识、服务端密钥、任务查询/回调与对象存储。
2. 中国大陆短信登录：供应商、签名、模板 ID、测试手机号与账号后端。
3. 自动续订会员：App Store Connect / Google Play 月卡和年卡商品 ID、沙箱测试账号、服务端收据校验与额度账本。
4. 云同步、私密分享和公开社区：账号体系、存储、内容审核、举报与删除协议。
5. 品牌限定、优惠券和合作内容：真实合作方、授权素材与规则；没有合作时保持空状态。

端侧自动抠图的兼容策略：iOS 16+ 真机使用系统主体抽取；iOS 15.1 仍可运行 App，但该功能降级为原图贴纸。Android API 24+ 使用 ML Kit 主体分割，缺少 Google Play 服务或识别不到主体时同样降级。最终抠图边缘质量必须在真机和人物、宽松衣物、透明杯、相近背景、多人以及复杂餐盘样本上验收。

免费端侧编辑已经支持滤镜强度、亮度、对比度、饱和度、色温、中心比例裁切、90° 旋转、水平/垂直翻转、±15° 拉直及撤销/重做。它定位为生活记录所需的轻量编辑器，不宣称具备人像精修、自由透视或局部蒙版等专业修图能力。
