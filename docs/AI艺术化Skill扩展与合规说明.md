# 吨吨记 AI 艺术化 Skill 扩展与合规说明

更新日期：2026-09-04

## 本次落地

客户端与服务端白名单已从 4 种扩展到 12 种：奶油海报、果冻拼贴、雨天手帐、糖纸丝印、票根小志、拍立得小记、蜡笔涂鸦、水彩咖啡馆、CCD 闪光夜、编辑部拼版、软糖绘本、纸艺小剧场。

客户端只发送不可注入的 `style_id`；具体提示词与保真约束只存在服务端。所有提示词都要求保留人物身份、穿搭、杯型、饮品与食物种类，限制乱码、伪品牌、过饱和和第三方 IP 模仿。

## 为什么没有直接安装陌生仓库里的 Agent Skill

Codex/Claude 的 `SKILL.md` 是开发助手工作流，不是手机 App 可调用的生产能力。把它“装进开发电脑”不会让用户手机获得图片处理能力，还可能引入未知脚本、密钥读取与许可证风险。因此本次把可用能力做成了真实的移动端风格目录、服务端白名单和火山方舟图片编辑调用，而不是只增加几个开发工具名字。

## 调研结论

- 小红书/抖音公开内容中反复出现的方向是撕纸拼贴、票根、拍立得、CCD 直闪、蜡笔、水彩、杂志拼版和手帐纸张；本次据此做了原创命名与视觉约束，没有复制博主素材。
- [InstantStyle](https://github.com/instantX-research/InstantStyle)展示了“内容与风格解耦”的思路，适合后续提升照片主体保真；但其仓库根目录未提供明确 LICENSE，本项目不直接复制代码。
- [IP-Adapter](https://github.com/tencent-ailab/IP-Adapter)使用 Apache-2.0 许可证，可作为未来自建风格参考图管线的候选，但模型权重和底模仍需逐项检查许可证。
- [ComfyUI_IPAdapter_plus](https://github.com/cubiq/ComfyUI_IPAdapter_plus)提供精确风格迁移工作流，但代码为 GPL-3.0；在闭源生产服务中引入前需单独做许可证评估，本次不直接集成。
- [InstantID](https://github.com/instantX-research/InstantID)代码虽为 Apache-2.0，但官方说明其人脸模型与发布权重仅供研究；不适合直接用于本产品商业人像艺术化。

## 推荐技术路线

首发继续使用火山方舟兼容的图片编辑模型：零 GPU 运维、按次付费、适合“会员每天一次”。未来当日生成量稳定后，再评估基于 Apache-2.0 组件的自建 IP-Adapter 管线。人物照片默认启用更严格的身份保持提示词；若模型无法稳定保持五官，则该风格不对人物分类开放。
